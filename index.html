Isi semua tabel fungsi dengan tarif OJK Wilayah 1:

Rate Comprehensive Mobil Penumpang —

Non bus & non truk (OJK kategori 1–5), berjenjang menurut harga pertanggungan.

Harga pertanggungan s.d (juta) — kosong = ke atasRate %

Harga pertanggungan s.d (juta) — kosong = ke atasRate %

Unduh Cadangan

Simpan satu file berisi semua pengaturan: rate, perluasan, teks polis, kendaraan, tampilan, perusahaan, logo, dan foto header.

Simpan file ini di tempat aman, misalnya Google Drive. Disarankan mengunduh cadangan setiap selesai mengubah rate.

Pulihkan dari File

Pilih file cadangan (.json). Pengaturan dimuat ke formulir dan baru berlaku setelah Anda klik Simpan. Riwayat dan pesan Inbox digabungkan, tidak menghapus yang sudah ada.

Cadangan Otomatis Tahunan

Cadangan dibuat otomatis sekali setahun, saat admin pertama membuka aplikasi pada atau setelah 1 Januari. Berisi pengaturan dan daftar kendaraan (logo & foto header tidak termasuk). 20 cadangan terakhir disimpan dan bisa dipulihkan.
